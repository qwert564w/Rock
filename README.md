# Rockstar Client - Optimized for Low-End PCs

## About
Rockstar Client for Minecraft 1.21.11 with automatic optimization for weak PCs (Intel/AMD integrated graphics).

## Features for Low-End PCs
- Automatic GPU detection
- JavaFX dependencies removed
- Heavy shaders disabled on integrated graphics
- Framebuffer safety checks

## Requirements
- Minecraft: 1.21.11
- Fabric Loader: 0.19.3+
- Fabric API: latest version
- Java: 21+

## Installation
1. Download latest release from Releases
2. Install Fabric Loader for 1.21.11
3. Install Fabric API
4. Put JAR file in mods folder
5. Launch Minecraft

## Troubleshooting
- Check Java version: java -version (must be 21+)
- Update Fabric Loader
- Check logs in .minecraft/logs/latest.log
- Increase RAM: -Xmx4G in JVM arguments
